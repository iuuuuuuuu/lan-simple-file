# v0.1.0-beta.9

Windows x64 与 Android beta，构建号 16。沿用此前的设备身份、数据目录和 Android 发布签名。

## 本次修正

- 底栏切换为 Miuix 自带的 GlassNavigationBar，使用真实的玻璃材质、背景采样与液态选中滑块。支持点击和拖动切换，保留未读角标、悬停提示及键盘操作。
- 取消底部整条固定占位，联系人列表和页面背景延伸到底栏后方。导航高度 56 像素，距窗口底边 12 像素；手机额外遵守系统安全区。
- 列表仅在滚动末尾保留避让距离，最后一项可以完整滚动到可操作位置。桌面新建分享按钮靠近右下角，窄屏时位于底栏上方；聊天输入框与发送按钮避开导航，软键盘出现时隐藏底栏。
- 保留 beta.8 的统一字重、Lucide 图标、快速隐藏窗口、分享长按拖动和分组管理。
- 构建流程增加 SQLite 原生依赖的 GitHub 资产 API 下载、重试和校验缓存；二进制与上游元数据必须同时符合已锁定哈希。

## 安装包与验证

- Windows x64：安装程序 EXE、便携 ZIP。
- Android：ARM64、ARMv7、x86_64 独立 APK。
- 后台验证覆盖液态滑块拖动与回弹、明暗主题、窄屏和宽屏布局、系统安全区、未读角标、键盘避让、聊天发送以及分享列表末尾与悬浮按钮。
- 发布流程继续执行静态检查、串行功能回归、网页与 Android 原生回归、Windows 隔离桌面启动和退出，以及安装包版本、架构和签名检查。

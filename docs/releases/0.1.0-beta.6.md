# v0.1.0-beta.6

Windows x64 与 Android beta。

当前为候选版本，尚未发布。电脑访问 Android `.local` 域名的端到端复测仍待完成。

## 本次更新

- Android 启动图标改为应用的蓝色文件分享标志，补齐自适应图标与各密度资源，应用名显示为“局域网简易文件”。
- 修复 Android 原生窗口状态栏默认黑色的问题，浅色和深色主题使用相应的状态栏图标，横屏同样保留安全区域。
- 默认昵称优先读取用户设置的系统设备名，兼容不同系统的存储位置和权限差异；机型仅作后备。保留应用内手动修改的昵称。
- 附近的人和设置页显示并可复制设备 ID；附近的人支持按名字、完整 ID 或部分 ID 搜索，重名设备可以分别查找。现有设备 ID 保持不变，改名和升级不会重新生成身份。
- Windows 发现在线设备后会在后台读取该设备的局域网域名，为手动代理追加对应域名的绕过规则，保留原规则；同时保留手机实际网页端口。
- Android 应用可见期间持有 Wi-Fi 组播锁，支持附近设备发现与域名查询，离开前台后释放该锁。

## 下载与升级

- Windows 使用 Setup EXE 或便携 ZIP；Android 按架构分别提供 ARM64、ARMv7、x86_64 APK，多数手机选择 ARM64，MuMu 选择 x86_64。
- 电脑和手机均应升级，才能自动交换带设备 ID 的域名信息。更新时保留原应用数据。
- 手机“我的分享”地址若含端口，浏览器访问时也须带该端口。

## 验证与限制

发布前运行静态检查、功能回归和 Android 原生设备名测试；发布流水线验证 Windows 启动、打包及 Android 签名、架构和版本。

设备 ID 标识一份安装身份，不是跨设备账号。清除应用数据或卸载后重新安装会产生新身份。

域名访问要求局域网互通、UDP 5353 可达和访问端支持 mDNS。自动代理修复针对 Windows 当前用户的手动系统代理；PAC、独立浏览器代理及 VPN 的规则由对应软件管理。旧版 Android 浏览器的 .local 解析支持因版本而异。

MuMu 验证不等同于小米真机验证；小米系统能否公开其自定义设备名仍需真机复核。Android 最低 API 24，沿用原发布签名。Windows 安装程序尚无代码签名。

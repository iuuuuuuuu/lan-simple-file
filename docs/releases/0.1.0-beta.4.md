# v0.1.0-beta.4

Windows x64 与 Android beta，安装包由 GitHub Actions 构建并发布。
beta.2、beta.3 未通过发布流水线，没有公开安装包；历史标签保持不变。

## 下载

- Windows：Setup EXE 为当前用户安装；ZIP 为便携版，解压后保留 DLL 和 data 目录。
- Android：多数手机使用 ARM64；老设备使用 ARMv7；MuMu 使用 x86_64。
- SHA256SUMS.txt 用于校验各安装包。

## 本次更新

- MuMu NAT 增加已签名 HTTP 发现，可与新版宿主机认证聊天并同步撤回。
- 设备列表显示平台标识；安卓默认昵称读取系统设备名称，默认头像使用 identicon_dart。
- 安卓窄屏导航和布局优化；分享加号增加文件夹选择，修复菜单穿透与 SAF 目录误判。
- 安卓可从设置进入“所有文件访问”系统授权页，返回应用后复核真实状态。
- 昵称使用弹窗编辑，支持中文；设置操作提示改为浮层 toast，不占页面空间。
- 桌面拖入文件或目录后立即刷新“我的分享”，保留搜索条件，单项失败不阻断其余项。
- Windows 代理未绕过 .local、使用 PAC 或代理状态读取失败时，新分享链接回退到局域网 IP，不修改系统代理。
- Windows 提供安装程序、卸载入口和可选开机启动，网页可下载安装程序。
- 修复 Windows 云端稀疏大文件和 PowerShell 编码测试夹具，保留原始验证断言。

## 验证与限制

发布流水线先运行静态检查与 Windows 串行功能回归，再构建 Windows 和签名 APK，
校验 APK 签名、版本、架构、ZIP 内容与上传文件 SHA-256，全部成功后才公开发布。
字体相关 golden 截图单独在有 simhei.ttf 的本机验证，不在托管 runner 上冒充验证。
本机后台回归已覆盖桌面拖入事件、真实文件与 SQLite；无窗口浏览器已验证网页打开和下载字节一致。

Windows 与 MuMu Android 12 x86_64 已实测；安卓真手机、跨物理电脑与 macOS 仍待实测。
Android 最低 API 24。所有文件访问不会解除系统选择器限制，Android/data、Android/obb 与应用私有目录仍受保护。

发布签名 APK 无法直接覆盖以前的 debug 测试版；卸载测试版会清除其应用数据，请提前保留需要的数据。
后续发布版沿用同一签名。Windows 安装程序尚无代码签名，系统可能显示发布者未验证提示。

旧 .local 链接不会自动变成 IP 链接。升级后重新复制网页链接；需要继续使用域名时，请在自己的代理设置中绕过 *.local。
浏览器独立配置的代理或 VPN 也可能阻断局域网地址，应用不会改写这些设置。

源码与安装包采用 GPL-3.0-only，相应源码由同一发布标签提供。

# v0.1.0-beta.10

## 本次修正

- 修复两级局域网分享域名在本机 Windows 系统解析器中不触发 mDNS 查询的问题。修复前局域网 IP 可访问，但域名解析失败，经过本机代理的请求返回 502；用户报告的 503 尚未直接复现。
- 将昵称和完整设备 ID 合并为单个 mDNS 主机标签，例如 `iuuuuuuuu--p-jpzsvuhxef46s.local`；单标签形式会被系统解析器正确发送到 mDNS，同时继续保证同名设备可区分。
- 中文昵称整体使用 IDNA 编码，长昵称只截短昵称部分，完整设备 ID 始终保留。
- 保留旧的两级 `.local` 名称识别，便于升级期间读取已有节点信息；新发布链接使用单标签格式。更新后需重新复制分享链接，旧链接不会自动变成新地址。

## 验证

- mDNS、冲突重命名、代理绕过、对端域名读取和分享链接定向测试通过。
- 在当前局域网通过系统 DNS 解析新域名，并完成 HTTP 请求。
- 分享分组移动端和桌面端 golden 测试已更新并通过。
- MuMu 的旧域名解析失败、IP 访问成功；模拟器随后退出，新格式在 Android 端的实际访问仍待验证。

# 0.1.0-beta.12

## 默认使用局域网 IP 分享

- “我的分享”主页、分组、单个文件的网页链接及二维码默认使用局域网 IP 和实际端口，例如 `http://192.168.1.23:47778/`，不再依赖接收端解析 `.local` 域名。
- 保留原来的复制链接和扫码入口，无需选择链接类型，也不要求用户为域名配置代理例外。
- 聊天中打开对方分享时，同样使用发现服务提供的 IP 与端口；对方离线时继续显示离线提示。
- 域名正在注册或组播不可用时，只要有局域网 IP，就不再阻止显示、复制分享地址或生成二维码。IP 变化后，分享页刷新地址和卡片中的链接；旧链接不会自动跟随 IP 改变，请重新复制或扫码。
- 保留分享路径、实际端口、显式传入的访问凭证与既有访问权限；仍发布 `.local` 域名以兼容已有使用方式。
- Windows 与 Android 版本为 `0.1.0-beta.12`，构建号为 19。

## 网络条件

两台设备仍需处于可互通的局域网，分享应用需保持运行并允许防火墙入站访问。此版本消除了默认链接对 mDNS 和域名代理例外的依赖；如果代理或 VPN 强制接管局域网 IP，或路由器启用设备隔离，仍可能无法访问。无需中继服务器，文件继续在局域网内传输。

## 回归验证

- 覆盖域名已就绪、注册中及注册失败时的 IP 地址显示、复制和二维码。
- 覆盖 IP 变化后的链接刷新、本机与对端分享地址、端口与凭证保留、离线错误和真实 HTTP 下载。
- 发布流程执行静态检查、串行功能回归、后台网页导航回归、Windows 启动与安装升级回归，以及 Android 原生测试、签名、版本和架构校验。

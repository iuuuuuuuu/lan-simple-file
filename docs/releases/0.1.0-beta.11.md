# 0.1.0-beta.11

## Windows 安装体验

- 点击安装后自动退出安装目录里正在运行的客户端，解除文件占用后继续升级，无需手动退出或反复点击“重试”。
- 支持窗口打开、缩回托盘和静默启动状态。新版客户端通过正常退出流程保存数据并停止后台服务；旧版本或未响应进程由安装器兜底关闭。
- 修复 Windows 完成服务与托盘清理后，仍可能卡在 Flutter 引擎销毁、使进程继续占用安装文件的问题。
- 按可执行文件的完整路径和进程启动时间识别目标，不关闭其他目录下的便携版。不会自动重启旧版进程，安装完成后仍可选择启动新版。
- 如果原客户端以管理员权限运行，普通安装时 Windows 可能要求授权关闭；静默安装不会弹出提权窗口，权限不足时返回错误。
- 保留 beta.10 的局域网单标签域名修复，Windows 与 Android 构建号升至 18。

## 回归验证

- 新增独立桌面的真实安装回归：首次安装、普通窗口、托盘模式和拒绝退出的旧进程，覆盖交互向导与静默安装。
- 安装回归校验进程退出、安装文件哈希、其他目录同名进程继续运行和已有数据保留。测试不切换用户桌面。

# v0.1.0-beta.7

Windows x64 与 Android beta，构建号 14，可覆盖此前正式签名的 beta.6，保留身份和应用数据。

## 本次更新

- 局域网地址使用 `昵称.完整设备ID.local:47778`，同名、同型号设备有不同地址。昵称可修改，设备 ID 延用现有身份；中文昵称会编码成浏览器兼容的 IDNA 标签。端口占用时顺延，页面、复制链接和二维码使用实际端口，不再尝试监听 80。
- 我的分享支持创建、重命名、删除分组，将多个分享移动到分组，拖动调整分享与分组的顺序，并复制分组链接或二维码。删除分组保留原文件和分享，默认文件夹优先，可恢复默认排序。
- 网页根目录与聊天头像中的分享抽屉显示同一分组和所有者设置的顺序。分组链接支持刷新与浏览器回退；分组是展示分类，原访问权限继续生效。
- 手机底栏改为 Miuix 悬浮导航，四页为聊天、分享、传输记录、设置。去掉中央上传按钮，创建分享按钮移到分享页右下角；桌面保留四项侧栏导航。
- 新增聊天记录与文件搜索：全局搜索、当前聊天搜索、全部/文字/文件筛选，选中结果后定位原消息并可返回最新消息。撤回、本地删除的消息和已删除会话不会出现在搜索结果中。
- 传输记录替代旧占位页面，接入网页文件和 ZIP 发送、部分内容发送、外部下载交接及已有传输任务，支持文件名或来源搜索、收发筛选、批量删除记录、复制文件链接，以及已知本地文件的打开与定位。
- 外部应用接管文件后显示“已交给外部应用”，不会误报为下载完成；删除记录保留文件，也不取消正在进行的任务。

## 安装包

- Windows：当前用户安装程序 EXE 和便携 ZIP。
- Android：ARM64、ARMv7、x86_64 独立 APK。多数手机使用 ARM64，MuMu 使用 x86_64；继续沿用原发布签名，手机提供的网页没有 Windows 客户端下载入口。
- 建议局域网内各设备均更新，以交换新的完整域名和分享分组信息。旧域名链接会因本次域名结构调整而变化，请重新复制。

## 验证与使用范围

发布流水线执行静态检查、串行功能回归、后台浏览器回归、Android 原生测试，以及 Windows 启动、打包和 Android 签名、版本、架构验证。手机与桌面界面在本机以离屏截图和交互测试检查，不连接用户实体手机或接管桌面操作。

域名访问仍需要局域网互通、UDP 5353 可达和访问端支持 mDNS；本版不依赖公共 DNS。手动系统代理可自动追加本机或发现的设备域名，PAC、独立浏览器代理和 VPN 的规则仍由对应软件管理。

设备 ID 代表一份安装身份；改名和覆盖更新不会更换 ID，清除应用数据或卸载后重新安装会产生新身份。第三方下载的最终进度、保存位置与完成状态由相应下载应用管理。

# v0.1.0-beta.5

Windows x64 与 Android beta。

## 本次更新

- 桌面设置“窗口与托盘”新增“静默启动”，默认关闭。开启后手动启动和开机启动均直接进入托盘，分享继续运行；点击托盘图标打开窗口。
- 托盘初始化失败会显示窗口；命令行 `--silent` 可临时静默启动，`--show` 可强制显示，均不改变保存的设置。
- 修复 Windows 彻底退出时同步销毁原生窗口导致的崩溃。
- “我的分享”显示并复制本机域名，访问根域名可查看有效分享；受保护的分享仍需原有访问验证。
- 修复管理员启动的 Windows 客户端无法拖入文件或文件夹的问题。
- Windows 手动代理未绕过本机域名时，自动追加该域名的绕过规则并刷新代理缓存，保留已有规则。
- Android 按手机架构拆包；Android 提供的网页移除 Windows 客户端下载入口和路由。
- 补充旧安装防火墙规则升级回归；修复发布流程中的 Android 插件注册与草稿附件校验。

## 下载

- Windows：Setup EXE 为当前用户安装，ZIP 为便携版。保留便携版的 DLL 和 data 目录。
- Android：多数手机选择 ARM64，老设备选择 ARMv7，MuMu 选择 x86_64；无需下载其他架构。
- SHA256SUMS.txt 包含每个安装包的 SHA-256。

## 验证与限制

发布流水线运行静态检查和串行功能回归，构建 Windows 与签名 Android APK，验证版本、架构、签名、便携包内容及上传摘要后才公开发布。

域名访问要求局域网互通、UDP 5353 可达且访问设备支持 mDNS。旧版 Android 浏览器可能不支持 .local 解析；本机 MuMu 的兼容映射属于模拟器环境配置，不包含在安装包内。
PAC、浏览器独立代理与 VPN 需要在对应软件中配置局域网直连，应用不会改写这些规则。

Android 最低 API 24。发布版沿用原发布签名；旧 debug 签名测试版无法直接覆盖安装。
Windows 安装程序尚无代码签名。安卓真手机、跨物理电脑与 macOS 仍待实测。

源码与安装包采用 GPL-3.0-only，同一发布标签提供对应源码。

# v0.1.0-beta.8

Windows x64 与 Android beta，构建号 15。可覆盖此前使用相同发布签名的版本，保留设备身份、聊天记录和分享配置。

## 本次更新

- 桌面与手机统一使用 Miuix 悬浮底栏，保留聊天、分享、传输记录、设置四个入口。桌面聊天仍保持联系人与会话并排，本机头像入口移到顶部右侧。
- 应用操作图标统一为 Lucide 线性图标，按钮、菜单、弹窗与底栏继续使用 Miuix。正文采用常规字重，标题采用中字重，Miuix 与页面文字使用相同字体设置。
- 选择彻底退出后先隐藏窗口，再完成网络连接、分享服务与数据库清理。清理过程中禁止托盘重新打开窗口；如果退出失败，恢复窗口并提示原因。
- 我的分享可直接长按卡片拖动排序，插入位置会显示标记。拖到分组入口即可移动分享，支持移回未分组；松手自动保存，失败恢复原排列。
- 分组入口显示分享数量，可直接创建分组；长列表和横向分组栏支持拖动到边缘自动滚动。搜索结果中调整顺序时保留未显示的分享。
- 原有“分组与排序”管理入口继续提供批量移动、分组重命名与删除、分组排序及恢复默认排序。分享分组与顺序仍同步到网页根目录和聊天头像的分享列表。

## 安装包

- Windows x64：当前用户安装程序 EXE 与便携 ZIP。
- Android：ARM64、ARMv7、x86_64 独立 APK，沿用原发布签名。多数手机使用 ARM64，MuMu 使用 x86_64。

## 验证范围

发布流程执行静态检查、串行功能回归、后台网页回归、Android 原生测试、Windows 隔离桌面启动与退出验证，以及安装包版本、签名和架构检查。

本次交互测试覆盖真实长按拖动、前后排序、跨分组移动、空分组、搜索结果排序、取消拖动、边缘滚动、慢速保存和失败回退。离屏截图覆盖桌面与手机、明暗主题及放大文字。测试不接管用户桌面，不连接用户实体手机。

局域网地址继续使用 `昵称.完整设备ID.local:47778`，端口占用时使用页面显示的实际端口。域名访问仍要求网络互通及访问端支持 mDNS；原访问权限不因展示分组而改变。
